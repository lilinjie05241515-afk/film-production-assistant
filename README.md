# 影视制作助手

面向 Windows 上 Codex／ChatGPT 桌面本地工作模式的影视创作插件。把故事讨论、编剧、导演、美术、特效、提示词和资料管理放进同一套项目流程，保留每份成果的准确版本、审核记录及工作对话关联。

**当前发行：1.16.0。** 本版将项目目录与对话索引搭建助手纳入安装包，保留 1.15.2 的项目管理、连续阅读和素材管理功能。音乐创作技能留待后续接入。

[下载发行包](https://github.com/lilinjie05241515-afk/film-production-assistant/releases/latest) · [安装与升级](release/installer-guide.md) · [1.16.0 更新说明](docs/integration-1.16.0.md) · [发行维护](release/release-guide.md)

## 可以做什么

插件内置八个专业方法模块，无须为核心流程另装原来的独立技能：

| 模块 | 负责内容 |
| --- | --- |
| 编剧 | 原创剧本、AI 短剧、大纲、人物小传、导演反馈修订；包含小说创作与小说改编方法 |
| 导演 | 表演、调度、摄影、构图、剪辑和声音的拍摄方案 |
| 美术总监 | 全剧风格、人物与场景视觉方向、资产设计指导及画面复核 |
| 特效 | 特效使用判断、表现、时序、空间与环境反馈 |
| 资产与视频提示词 | 人物、场景、道具的资产提示词，以及逐场或逐镜视频提示词 |
| 影视分析 | 有来源依据的学习卡、分析报告和创作参考 |
| 灵感探索 | 创意讨论、方向比较和想法记录 |
| 需求与执行规划 | 明确目标、范围、阶段、约束和交付要求 |

对外技能入口为**影视总控、编剧、美术总监、头脑风暴接口**。其他方法由总控按任务加载。头脑风暴接口负责准备交接输入，外部生成提供方尚未连接；日常创意讨论使用内置灵感探索模块。

看板用于进度、文稿、素材和审核状态查询，以及文件分类、更名、导入、导出和逻辑回收。创作、修订、采用、渲染与工作对话搭建在聊天中按明确要求执行。

## 从一个项目开始

安装并核验插件后，在工作对话说明作品名称、保存位置和创作路线。例如：

> 在我指定的项目文件夹新建一部 AI 短剧，采用直接剧本路线，并搭建全部主要工作对话。

直接剧本路线包含总控、灵感与需求、编剧与修订、美术总监、导演与特效、资产与视频提示词、审核与交付七个主要入口。小说改编路线增加小说创作；纯小说路线使用与小说工作对应的入口。

总控先核对现有项目和真实对话，复用已有关联后补缺项。新对话只核对职责并等待任务，避免因搭建工作区就开始整部剧的创作。每位使用者可以明确选择今后默认搭建完整工作区；安装包不会继承原开发者的个人授权。

项目文件夹会生成 `AGENTS.md`、`项目入口.md`、分类目录和 `09-任务与接续/工作对话/对话索引.md`／`.json`。真实聊天仍由客户端保存，对话索引记录最近登记的真实 ID、职责、范围和状态。接续时重新读取项目与准确成果版本。

本地工程与客户端侧栏项目分别核验。若宿主无法创建客户端项目或暂时无法确认聊天归属，会保留具体待处理状态，不用重复创建来掩盖未知结果。

## 安装与换电脑

从仓库的 **Releases** 下载 `film-production-agent-1.16.0-stable.zip` 及同版 `.zip.sha256`，按[安装指南](release/installer-guide.md)完成以下步骤：

1. 核对下载的 SHA-256，完整解压发行 ZIP。
2. 用包内安装器检查环境、核验并部署到所选本机目录。
3. 运行 `host-plan`，把生成的本地 marketplace 接入桌面插件管理。
4. 在新会话中核实 `film_health` 返回 `1.16.0`，再使用项目看板与工作对话。

需要 Python 3.11+；图片、视频、音频的部分探测、预览与渲染还需要 FFmpeg／ffprobe。插件不要求额外模型 API，也不启动独立 HTTP 网站。

GitHub 仓库和 `git pull` 用于取得程序与更新包，不会自动切换正在运行的聊天。另一台电脑需要单独安装；作品、个人规则和本机路径按实际范围另行迁移。插件身份保持 `film-production-agent@film-production-local`，升级时沿用原安装目录和数据目录。

## 版本与能力边界

- 候选、用户采用、当前通过版和任务冻结版本分别保存。新候选不会覆盖已通过总稿。
- 云端工作稿和批注由宿主 Pages 工具处理；相关工具必须在当前客户端可用。按轮同步不代表后台实时双向同步。
- 音乐、音频、配乐位置及已有素材可以登记和管理；本版没有集成音乐创作技能，也没有连接音乐或视频生成提供方。提示词交付不等于媒体已经生成。
- 第三方参考库、登录信息及个人资料不随包分发。影视研究和特效模块的可选外部资料需在目标环境单独配置。
- Windows 之外的平台和真实异机运行情况，以对应版本实际验收记录为准。

## 维护与分发

源码与完整专业方法随项目保存，发行包包含固定版本的运行代码和模块摘要。先在隔离 TEST 项目验证改动，再构建新版本；既有发行包与 Git 标签保持不变。[发行指南](release/release-guide.md)说明构建、校验、发布目录与更新获取流程。

用户可以从公开仓库下载并使用发布包。各模块来源及分发记录随包保留，见 `modules/manifest.json`；此次公开下载与使用由项目发布者授权。本仓库没有额外套用统一开源许可证，第三方依赖仍遵循各自许可；未声明或尚未核实的上游许可保持原状态，不因仓库公开而标记为已核实。
