# 篇幅、文体和体裁的任务适配

只有需要跨短篇、章节、长篇或风格切换时读取。先从作者指示与原文辨认本次交付的**形式职责**，再选准备材料和复读问题；不预设“网文开篇”是所有小说的默认形式。字数、视角、人称、语言密度、开放程度和结尾方式以作者要求及作品本身为准。

| 交付 | 主要准备 | 复读重点 |
| --- | --- | --- |
| 独立短篇 | 当前人物关系、一次主要变化、可用篇幅；必要时少量背景 | 开端与结尾是否形成完整体验；可开放但不能只停在半途；不强求续章钩子 |
| 长篇单章 | 前后章状态、人物目标、时间与物件、已埋伏笔、该章在大弧线中的职责 | 本章的变化是否推动或加深长线；慢章可积累关系和气氛，非每章都要反转 |
| 连载开篇与更新章 | 既有承诺、当场阅读期待、读者已知信息和下一步方向 | 本段的回报和后续牵引分别成立；按 [web-serial-writing.md](web-serial-writing.md) 复读 |
| 多章或整部长篇 | 全书 Canon、卷章弧线、相关原文、时间/物件/知情账、作者声音样本 | 跨章人物变化、因果、伏笔与节奏分布；不能仅靠单章评分推断长期一致 |
| 同事件不同文风 | 固定事件、视角和事实；作者认可的文本样本或明确的风格目标 | 词汇、观察重点、句段快慢、对白分寸与情绪距离可辨，且事实不漂移 |

体裁提供阅读期待，但不规定统一句式、对白比例或剧情节拍。悬疑可以安静而有推理空间；喜剧可温和或荒诞；日常可只通过分寸推进；古风、动漫感、游戏等可混搭。区分**体裁**（读者期待什么）、**文体**（怎样叙述）、**形式**（短篇、章节、连载、长篇）和**作者声音**（既有原文的稳定选择）；它们不能由单个标签互相替代。若作者给原文或明确语气，以作者文本和指令优先；没有样本时写出符合目标的候选，不假称已学会作者声音或模仿某位在世作者。

多题材同时写作时，再看**人物驱动力**：每位主角想得到、护住或遮掩的具体东西是什么，愿为此牺牲什么，遇到冲突会求证、抢先、回避、较量、照顾还是拖延？这些由题面、原文和人物经历决定，不给“正确主角性格”配额。若多篇都自动变成冷静体贴的主角替大家找折中办法，并在末尾约定下次合作，检查是否抹平了已给的自尊、私心、怨气、野心或竞争。允许善良和互助，也允许不合群的决定、暂时无法和解与有代价的胜利；后果须由现场因果支撑，不为制造差异强塞冲突。

需要 Agent 分工时，主控按任务复杂度调用必要角色。单篇写作可由一位写作者加主控复读完成；跨章与秘密较多时增加连续性核查；用户要求多轮稳定或对比时再安排独立读者与修订者。多文件任务把每篇或每章的字数、人称和固定事实分别核对；有一篇未到作者指定范围就只修该篇，另存修订稿再复读，不能拿整组总字数充数。评审表也随形式选择：共同硬项是视角、事实、因果、物件与字数；短篇看完整性和余味，长篇看跨章发展，连载看追读意愿，风格实验看表达差异与事实守恒。没有一个分数可以同时证明所有形式优秀。

如果一类输出反复出现相同问题，先定位是**局部正文**、**题材策略**、**形式选择**还是**通用 Skill** 所致，再在对应层级小改并用新题复测。不要为一个样稿设全局禁词、固定开头模式或统一结尾公式。
