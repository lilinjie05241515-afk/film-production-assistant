# 功能与工作入口

影视制作助手 2.1.0 内置八个专业方法，提供五个独立技能入口。入口数量不等于专业能力数量。用户可以从公开仓库下载并使用发布包；模块来源和第三方依赖许可说明随包保留。

| 能力 | 交付内容 |
| --- | --- |
| 编剧 | 原创剧本、AI 短剧、小说与改编，大纲、人物小传及修订 |
| 导演 | 表演调度、构图摄影、剪辑声音、特效需要判断与 Blender 白模预演 |
| 美术总监 | 全剧视觉方向、风格圣经、人物场景指导与画面复核 |
| 特效 | 使用判断、画面表现、时序空间及环境反馈 |
| 资产与视频提示词 | 资产设计文字、选型记录及视频提示词 |
| 影视分析 | 来源学习、证据分析、研究报告和参考限制词 |
| 灵感探索 | 想法展开、方向比较和讨论记录 |
| 需求规划 | 明确范围、约束、阶段与交付要求 |

独立入口为影视总控、编剧、导演、美术总监和头脑风暴接口。导演入口为 `$film-director`，可以直接承接拍法、镜头与节奏设计，按需调用特效方法及既有预演能力；与编剧共享项目资料和准确成果版本。总控按当前项目任务读取适用方法；脑暴接口只准备输入，外部提供方未连接。正常创意讨论可由内置灵感探索完成。

## 项目与对话

主要工作区按已选路线建立：直接剧本七类、小说改编八类、纯小说四类，纯小说美术入口按实际需要添加。主对话负责协调，专业对话等待具体任务；章节、人物或场景专属对话按明确工作范围创建。

随包目录助手生成项目协作入口、分类目录和可读对话索引。真实聊天由宿主创建并保存在客户端；索引保留登记时的观察，不替代最新状态核对。现有项目和准确对话先复用，未知创建不重复执行。

## 看板与素材

看板用于进度、文稿、素材和审核记录查询，以及文件分类、标签、更名、导入、导出和逻辑回收。资产提示词属于文字内容，资产图片、视频片段、音乐和成片分别管理。低清预览是查看便利，不代表原件完整质量验收。

看板内可明确确认准确文稿、选择已登记美术方案和对象用途素材；创作、修改正文、云稿写入、渲染及聊天搭建通过工作对话执行。保存候选、独立复核、用户采用及实际制作完成是不同状态。

## 当前范围

音乐创作技能尚未整合，插件支持已有音频、配乐位置、来源及关联记录；本版不调用音乐或视频生成提供方。云稿使用当前宿主的 Pages 能力，按轮读写与核验，不提供后台实时双向同步。外部影视资料库和可选研究来源需要另行配置。

独立安装的同名技能不会被插件自动删除，其后续修改也不会自动回流到插件。打包更新时应核对模块来源和实际版本，再形成新的不可变发行。

## 分层会话与交接

2.1.0 将分层会话扩展至灵感需求、编剧、导演、美术、资产和复核部门。部门主入口负责范围、派发与回收，章节或人物等独立执行对话承接具体任务；简单咨询可当场回答，跨职责执行先登记原话、准确输入版本、范围、交付物和回报目标，并由准确接收部门承接。

任务已提交、完成已登记、回报待授权／待执行／宿主已接收和用户已批准分别核对。完成登记不再强迫同时发送消息；父入口主动读取准确成果也能登记完成，未获授权的回报仍保留待处理。创建、发送和归档仍由宿主按真实授权执行；未知结果先核对，持久待办不是后台调度器。旧项目和冻结任务不自动迁移。

脑暴持续发散，用户明确选方向才进入相应深入；指定范围的临时深入不强迫关闭其他分支。偏好、约束、提问或“继续”不自动选定方向。状态、用户来源与准确分支版本保存在同一 planning 记录，保留历史，选定不等于采用或制作授权。接口可校验版本和记录结构，用户原话的含义仍由宿主判断。详见 [2.1.0 协作与发散](integration-2.1.0.md)。


1.18.0 将主导航收敛为项目总览、创作任务、素材库。任务按创作环节与状态展示，素材按人物、场景等对象及具体用途整理；确认记录收在总览。项目设置支持名称、介绍、封面、归档恢复与保留文件的移除。

2.0.0 新看板说明见 [双主题创作看板](integration-2.0.0.md)。

## 跨平台运行

2.1.0 提供 Windows 与 macOS 共用安装包，保留 26 个工具、8 个方法模块和 5 个公开入口。Python、媒体工具及可选 Blender 在目标机器核验，宿主配置由安装器重新生成。Mac 运行、包内文件与合成媒体验证以对应 CI 记录为准，原生客户端看板和真实会话不由 CI 代替。见 [Mac 说明](MACOS.md) 与 [2.1.0 接入](integration-2.1.0.md)。
