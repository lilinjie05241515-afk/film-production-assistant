# 1.12.0 按轮更新云端工作稿

总控中讨论故事、大纲等内容；形成第一份完整初稿时建立或准确关联云端工作稿。后续每轮明确修改完成后更新同一工作稿，并保存本地候选。工作稿无需先获得正式批准；用户采用准确版本仍沿用原批准机制。

film_cloud 提供持久策略、准确成果绑定、待处理写入及宿主观察。文本成果保存可携带 cloud_update 在同一事务中排队；检查点、导入旧观察和单纯讨论不触发。程序没有云端凭据，由当前宿主实际读取、编辑并完整读回，未知结果保留待核对，不重复建页或重发已经生效的修改。

界面展示云端文档、最后核对版本和待同步状态，保存后将明确的接续请求交给宿主；消息已送出不等于已同步。云端手动修改须先读取和保留，不能用旧本地稿或通过总稿无条件覆盖。默认按轮处理不代表后台实时双向同步。

接口见 integration-cloud-1.12.0.md，界面见 integration-cloud-ui1120.md，宿主执行见总控 references/cloud-round-workflow.md。旧工具和专业模块保留；本版只增加单个工作稿的同步协调，不扫描、迁移或批量上传已有真实作品。
