# 1.15.1 创作看板

用户要求：看板只关注创作与任务，开发维护相关的内容不要出现。

主导航为项目总览、创作任务、文稿资料、素材库、审核记录。首页优先呈现进行中的任务、需要关注的意见、下一步；已结束任务的下一步不出现在首页。任务页只读现有状态，打开已有工作对话继续，不发送消息或创建任务。

移除同步信息页、原始JSON详情、内部编号、校验摘要、系统版本、操作号等维护展示。云端工作稿在文稿页显示名称、同步状态和打开入口。保留作品版本、采用状态、专业意见、完整正文、差异、素材来源和文件操作。复制引用仍携带准确版本信息，后台身份核对、摘要验证、重复操作保护与未知结果恢复不变。

用户个人工作区默认规则由全局AGENTS.md引用，并保存在发行包之外。此更新不改动该规则、目录助手、专业模块、作品或原有任务执行锁；运行中的旧连接保留原版本。

验证边界：使用隔离合成数据测试；客户端原生面板的视觉与媒体播放需在重载新版本后实际验收。
