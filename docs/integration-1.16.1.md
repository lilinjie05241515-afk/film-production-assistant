# 1.16.1 现行规则整理

本版以已封存的 1.16.0 为基线，保留项目搭建助手、安装升级能力及八项专业方法。修改集中在执行说明与文档组织；数据 schema、业务接口和专业模块内容不变。

- [现行规则](current-rules.md)统一看板、工作对话、云稿、版本与授权职责。
- [兼容说明](compatibility.md)集中旧名称、旧类别、旧审批来源和任务恢复规则。
- 协作入口不再累积历史开发轮次。原记录及纯旧界面说明位于 docs/history，兼容链接保留。
- 当前看板只查询业务、管理文件素材和打开已关联对话；创作、改稿、采用、云写入、对话创建与发送任务在工作对话处理。
- 工作区尊重适用个人持续授权，已授权事项不重复询问；通用包不把某位用户的默认传给其他使用者。保留 1.16.0 包内搭建助手及真实宿主状态核验。
- 历史 panel/panel-click 证据保留，当前不再指导使用旧业务按钮。候选、通过版、任务冻结输入、云稿手改和未知结果恢复语义保持。

本轮不删除旧运行包、个人独立技能、作品文件或历史版本。专业方法依据当前清单按需加载。新运行版本不改已有任务锁；安装状态与当前聊天实际运行状态分别核验。本地接入与远端发布分别执行和报告。
