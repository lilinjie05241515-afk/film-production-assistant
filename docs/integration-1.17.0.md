# 1.17.0 macOS 安装与运行适配

本版以 1.16.0 为基线，为同一发行 ZIP 增加 macOS 安装入口和运行时路径适配。产品展示名仍为“影视制作助手”，技术身份保持 `film-production-agent@film-production-local`。既有 Windows 安装与作品数据分离规则继续适用。

## 本轮变化

- 新增 `release/bootstrap.sh`，从明确指定或已安装的位置寻找 Python 3.11+ 与 sqlite3，参数保留空格和中文。不自动下载软件、不修改 shell 配置。
- 环境检查记录真实操作系统、CPU 架构和 Python；平台支持范围与本次检测分别表达，不把识别出 macOS 当作已经完成客户端验收。
- 安装器继续为目标机器生成绝对 Python、脚本、catalog 与配置路径。Mac 与 Windows 使用同一套发行哈希校验、独立部署、升级锁、备份及恢复流程。
- 未指定 catalog 时，Mac 运行时使用用户的 Application Support 目录；显式环境配置及已有安装器选择优先。不会猜测、搬迁或合并旧 Windows 风格路径下的登记库。
- 媒体工具在当前 PATH 之外支持 macOS 常见 Homebrew 位置；用户显式工具路径仍有最高优先级，失效时明确报错，不自动切换来源。
- 补齐 Mac 安装、客户端接入、媒体依赖、Windows 作品迁移及验收边界说明。具体操作见同目录 `MACOS.md` 与发行 ZIP 根的 `release/installer-guide.md`。

## 保持的行为

八个专业模块完整内容与来源记录保留。编剧、导演、美术、特效、提示词、分析与规划的职责没有因操作系统改变；音乐创作技能仍未整合。项目搭建继续根据当前使用者的明确要求或有效个人默认执行，不携带开发者的持续授权。

看板继续查询业务状态和管理文件素材。创作、采用、云稿写入、聊天创建与渲染在工作对话中执行；候选与通过版、旧任务执行锁、准确版本及用户修改保护保持。

程序包没有真实作品、凭据、私人路径或聊天／Pages 绑定。不同电脑分别安装；同一账号登录、下载新版或 Git 同步都不等于另一台机器已安装、项目已迁移或当前聊天已重载。

## 验收与支持边界

适配测试覆盖操作系统分支、明确目录优先级、工具查找以及安装包真实 stdio 启动；具体通过项和 macOS CI 结果以本版发行回执为准。CI 的 macOS 操作系统运行证据与个人 Mac 上的桌面插件、看板、文件选择和媒体体验分开记录。

运行时不绑定单一 CPU 架构，但 Python、FFmpeg 和桌面客户端必须分别支持目标机器。Apple Silicon 与 Intel 的常见路径得到处理，并不表示已对所有机型或全部 macOS 版本完成认证。

旧版发行包及标签保持不可变。升级沿用本机数据和配置，遇到旧任务或 schema 检查阻挡时按原流程处理，不通过移除登记或重建任务绕过锁。
