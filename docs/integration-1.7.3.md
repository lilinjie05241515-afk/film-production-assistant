# 1.7.3 剧本分类说明

本补丁明确剧本分类的用途和阶段，沿用 1.7.2 的资产管理及 Markdown 能力。八个专业模块保持冻结，数据 schema、成果类别键、审批和依赖关系不变。

- **源剧本（底稿）**：`source_script`。保存导入原稿或基础剧本，作为后续加工依据；可以是完整剧本，也可以已经通过审核。
- **动态分场剧本**：`script`。保存按场次、人物对白及可演动作组织的剧本，供导演工作接续；同时保留既有剧本的兼容分类。
- 只有明确标记 `metadata.workflow_stage=dynamic_script` 的准确版本才显示为动态阶段。没有该标记的既有 `script` 显示“阶段未标注”，不根据分类名称、正文或历史批准状态自动推定。

分类导航、创作分类选择、分类说明、流程阶段及导出目录使用一致称呼。阅读、修订或批准均继续针对准确版本。分类用途说明不表示阶段完成；两类内容各自管理版本和审核状态，候选不覆盖已通过内容。

本补丁没有数据迁移，不扫描或打开真实作品，不改写旧稿正文及其阶段、分类或批准状态。旧运行任务继续使用原来的系统及模块执行锁。

发行、安装和目标聊天实际运行版本分别核验。既有聊天可能继续持有旧进程，不能用安装成功代替目标聊天的 `film_health` 结果。
