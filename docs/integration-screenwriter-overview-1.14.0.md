# 1.14.0 编剧与美术协作中的编剧能力

编剧模块 screenwriter 1.0.0 与 1.13.0 已有美术总监合并进入同一 1.14.0 系统。八项专业方法分别为编剧、美术总监、导演、特效、资产与视频提示词、影视分析、灵感探索和需求规划。四个公开入口为影视总控、编剧、美术总监与头脑风暴接口；接口准备仍不代表外部脑暴提供方已接通。

编剧统一承接原创剧本、小说改编、小说与修订，优先服务完整可表演的 AI 短剧。小说和改编完整方法保留在 modules/screenwriter/methods 内，按需加载，原来源副本保留在 compatibility-sources。旧调用别名进入对应内部模式，不覆写用户独立技能或旧任务锁。film-screenwriter 负责故事文本，film-production-agent 负责项目、准确版本与制作交接。

直接剧本从创意、梗概、人物或已有剧本进入完整分场正文，不强制先写小说或额外底稿。底稿 source_script、大纲与人物资料按需使用，旧成果分类与项目路线保持原选择。题材、画幅、集数和时长由具体作品决定，不自动套用固定短剧结构。

导演反馈引用准确剧本、范围、场次与原句，说明问题、预期效果和必须保留项。编剧先判断影响，在约定范围内交完整修订候选；重大剧情、动机、关系、结局或规则变化由用户决定。反馈记录不代替正文或采用，正文仍通过既有成果与任务接口完整保存。独立复核、处理状态、云稿同步和用户采用分别记录。详细契约见[编剧意见接口](integration-screenwriter-1.13.0.md)及[日常接续](../skills/film-production-agent/references/screenwriter-workflow.md)。

美术总监继续负责视觉定调、时代与环境质感、场景及资产设计指导和实际画面复核。其主备方案、唯一全剧基准、基准内修订、旧已采用基准接续和云端手改保留能力完整延续，见[美术工作方式](../skills/film-production-agent/references/art-direction-workflow.md)。编剧读取已采用的准确风格，不能以文字修订替换视觉基准；美术也不能为外观便利改动剧情、动机或世界规则。冲突回到具体版本与已授权范围，不让两个角色自动追随“最新稿”无限返修。

小说与剧本的对话槽位保留，美术职责独立；统一专业方法不自动合并、改名或新建用户聊天。进入工作对话、发送修改要求、创建聊天和制作媒体分别遵循对应授权。新候选不改变通过指针；正式采用新版后按完整版本依赖标记需复核，不自动重写或声称已完成语义影响分析。

完整初稿与明确修订沿用按轮云稿：实际读取、保留手改、保存完整候选、执行已授权同步并完整读回。同一成果的 ID、scope 与云页不因角色切换而改变，未知请求恢复原操作。现有 Markdown 阅读、编辑与导出继续使用同一正文来源。旧任务只能在匹配的冻结运行环境继续写入，不能因合并而重设执行锁。

本说明描述功能与职责，不证明任何实际作品、云稿或媒体已经修改。合成程序验证、方法行为样例、实际客户端交互、真实云端读写与用户审美采用按各自取得的证据报告。
