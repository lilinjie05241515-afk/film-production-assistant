# 环境互动、破坏与持续状态

当人物、载具、异种角色或既定能力作用于环境，且其反馈影响观看、行动或后续空间时读取。联读 [动作表现](action-impact.md) 与 [世界规则](world-and-period.md)；这里描述成片中的变化与交接，不提供现实破坏、爆破、搏斗或危险工序。

环境反应可以支持尺度、重量、压力、人物关系或感官体验，也可以很轻。先看本场需要什么证据，再决定是否损坏；安静戏不强加碎裂，强风格也须服从剧本权限与既定世界规则。

## 先核对受影响对象与授权

从冻结剧本、已采用设定与获准资产查明：对象 ID、所在位置、材质及已知状态、原有功能、作用来源、前后场用途、实际允许的变化。未知材质、内部结构、承载或破坏阈值保持未知，不用外观推成工程事实。

| 权限 | 可以怎样设计 | 需要保留的边界 |
| --- | --- | --- |
| `locked` | 将已有作用、损伤、结果和揭示顺序落实为可见/可听安排 | 不增减关键损坏、恢复、能力或可用路线；不能因难生成而换结果 |
| `director_open` | 在源授权内选择环境反应、可逆位移或轻微表面损伤，并说明呈现与连续性 | 轻微不自动等于获准；检查是否成为证据、伤害来源或后续阻碍。已明确允许则无需逐项再问用户 |
| `proposal_required` | 单列改变能力上限、关键出路、重要资产功能、人物结局等候选及影响 | 不自动写入执行方案或已确认资产；已有明确授权的变化按其范围执行，不重复审批 |
| `intentionally_ambiguous` | 呈现可确认的现象与人物所见 | 不以内部结构特写、全知声源或损伤诊断解释被保留的秘密 |

判断权限依据语义后果，不按“裂纹很小”“破坏很好看”决定。剧本已允许的具体破坏可以直接设计；原文沉默也不等于任何破坏都已开放。
缺项只阻断受影响的结论：可继续完成已知部分，给未知项与需要确认的影响，不把整场常规设计变成审批清单。

## 区分反应与损坏层级

| 层级 | 关注的成片变化 | 连续性重点 |
| --- | --- | --- |
| 环境反应 | 振动、尘水扰动、光影遮挡、可移动物偏移等，在已知世界中成立 | 哪些自然消退，哪些位置变化会留下；暂时看不见不代表自动复位 |
| 表面损伤 | 获准的擦痕、凹痕、剥落或局部裂口，尚未确认功能改变 | 位置、形状与范围持续；不能从痕迹直接推断内部失效 |
| 功能或结构损坏 | 物件无法承担原功能、阻隔被改变、通路或支撑发生变化 | 剩余功能、不可用范围、人体选择与后续空间必须更新 |

这三层不是必然升级链，也不是视觉强度刻度。大量尘雾可能没有结构后果；很小的获准损坏也可能决定关键功能。区分“观众看见了什么”和“世界中已确认发生什么”。
同一对象可以同时有多个层级；记录各自的依据与后果，不用统一“已破坏”抹掉仍可使用的部分。

## 按条件选环境反馈

### E1 只需让力量或尺度可感

- 条件：剧情需要空间对行动作出回应，但未授权改变通路、资产功能或人物状态。
- 拍法：选择已知环境中的参照关系、遮挡或获准扰动，让作用源、响应位置及人物反应有因果联系；可在同镜读清，不必另切破坏特写。
- 剪辑与声音：作用声与当地环境响应有时空关系，结束后保留必要余响；不要凭轰鸣补出画外大规模坍塌。
- 取舍：局部反馈能维持人物焦点，更大范围可显示规模；选择取决于本场视点。无重量、可穿透等既定规则不强加地面变形。

### E2 痕迹承接已发生的作用

- 条件：授权内的表面损伤支持接触质感、人物感受或事后辨认，且不另改关键功能。
- 拍法：保留作用位置和痕迹位置的对应；若痕迹本身承担线索，按既定揭示时机靠近，避免先拍特写泄露因果。
- 剪辑与声音：不要求每个细痕都有独立音效；用人物看到、触及或绕开已知痕迹的时机承接后果，是否触及需有剧本或导演开放依据。
- 取舍：痕迹可增强持续感，也可能成为新增证据。若它将改变他人判断或推动结局，重新核对权限，不能因尺寸小直接纳入。

### E3 功能损坏改变下一次选择

- 条件：冻结输入或明确授权已有破损、断开、堵塞、坍落或功能丧失，且影响行动。
- 拍法：先保证理解变化所需的原功能可读；发生时给出与作用源相连的空间变化，随后读到仍可用和已不可用的部分，以及人物如何调整。
- 剪辑与声音：关键功能变化不能只靠碎片蒙太奇表示；切点保留新阻隔、支撑或路线。延续声源须对应仍在变化的对象，不凭声音无限追加损坏。
- 取舍：大景可说明新空间，局部可抓住当事人感受；若离画表达已足够，可用后果验证，但不能靠突然出现的出口解决剧情。
- 权限：扩大损坏范围、增加伤亡或让原定出路消失均按源权限处理；未获准的改写另列提案，原授权方案继续可交付。

### E4 超常作用或特殊材质

- 条件：已确认世界允许无接触、反常重力、特殊材料、形变或其他特殊反馈。
- 拍法：将作用对象、触发、范围与残留绑定既定规则；通过获准的材料变化、位移或光影显露关系，不套用现实材质的统一破碎外观。
- 剪辑与声音：保留持续与结束的可辨线索；角色只能回应其能感知的变化，音效和光芒不能暗中增加能力范围或新信息。
- 取舍：视觉夸张可以成立，仍需控制状态延续。未知机制可保持神秘；不得为方便下镜擅自设定修复、消失或自动还原。

### E5 破坏后的环境成为下一步条件

- 条件：已有碎片、粉尘、变形、位移或残留继续影响后续人物、视线、声音或路线。
- 拍法：按剧情需要保留人物与残留的关系；可用经过、避让、接近或目光让后果持续存在，不必每镜重拍损坏全貌。
- 剪辑与声音：转换机位后继承可见范围内的状态；声音的遮挡或余响变化须有空间依据，尘雾消散的时间未知则不假定跨切点已经清空。
- 取舍：持续残留提高可信度，也会限制构图与调度；不能为画面干净让碎片消失，更不能擅加踩伤、滑倒等新后果。

## 材质、程度和叙事功能共同决定

先确定材质是源事实、获准外观设计还是未知；再判断世界规则允许怎样的反馈、这一变化服务何种观看目标，最后选择表现范围。不能仅凭动作类型决定“墙必裂、地必陷、玻璃必碎”。
材质不同的成片反馈可体现在形变方式、表面痕迹、碎片外观、持续运动与声音差别；具体表现是待核设计，不自动代表真实材料模拟准确。
若未知材料决定关键承受能力、失效或出路，保留缺项或提出候选；若只影响非关键外观且源允许设计，可给明确候选并保持其事实状态。
破坏程度既要回应作用，也要服务叙事：突出强弱、揭示代价、改变选择或支持感官体验均可；不能只写“更炸裂”而不说明损坏了什么、留下什么。
精确尺寸、数量、载荷与阈值无依据时不编造。需要空间说明可用已有地标和相对关系，避免把导演设计包装成物理计算或实际测量。

## 前、中、后状态交接

每个受影响资产用稳定 ID 连接镜头、动作事件和连续性记录；已有版本/哈希继续引用，缺少资产或媒体则标未知/待提供。拆分生成不新造未经登记的正式资产。

| 时点 | 需要能复述的内容 |
| --- | --- |
| 变化前 | 对象位置、朝向、既有损伤、原功能、与人物/通路/支撑/遮挡的关系 |
| 发生中 | 作用源、变化位置与方向、同时的人物行动、形变或位移进程；何时开始影响功能 |
| 变化后 | 最终位置、损坏范围、剩余功能、碎片或位移物落点、还在持续的运动/尘水/声音 |
| 后续承接 | 哪些镜头和场次继承，人体的可用动作与视线是否受影响，空间的通行/支撑/遮挡如何变化 |

- 位置优先关联稳定地标或世界方位；画面左右随机位改变，人物自身左右与损伤侧别单独写清。
- 碎片位置记录影响剧情的分布、可见范围和仍在移动的部分；未知精确数量保持未知，不强迫给每片碎屑建立资产。
- 人体影响写获准的反应或选择限制；不能从环境破坏擅推伤势，也不能忽略源中已经发生的受伤。
- 剩余功能不能只写“坏了”：说明哪些仍可用、哪些失效、哪些未知。局部损坏不自动升级成整物消失。
- 碎片被移走、尘雾消散、通道重开或物件修复都需要故事时间与可确认依据；未展示可以沿用获准省略，但必须保持可解释的前后状态。
- 同一破坏跨角度呈现时标清事件阶段；明确的重放可以再次呈现同一次事件，连续故事时间内不能让物件无依据恢复完整后重新破碎，也不能在换镜后扩大已完成的损坏。
- 新版本改动破坏时，指出受影响资产、镜头和后续依赖；旧版本保留，不能只改当下画面却让后续继续引用旧终态。

## 写进已有交付，不增加系统负担

主文直接说明“什么受到作用—怎样变化—人物怎样回应—余下什么—下一镜怎样接”。局部资料放进现有表演、调度、摄影、剪辑、声音、依赖与资产/连续性附属记录；详细字段以实际 Schema 为准，不新增必填字段。
给执行 Agent 的限制要包含不能恢复、不能追加、不能提前揭示的具体状态，以及可调整的构图与工序；平台参数和生成提示词由执行 Agent 适配。
破坏形变、多物体遮挡、碎片持续与光影衔接列为制作预判风险。可以提出拆分生成、分层合成或改观看距离等候选，但保留同一结果、空间和揭示顺序。
需提案的破坏与已授权方案分开保存。预览文本可展示候选后果，却不能标为用户已采用、正式资产更新或实际生成效果通过。

## 最后检查与证据边界

只检查本场真正受影响的对象：作用与变化有无联系；程度是否来自材质、规则和叙事条件；损伤是否改变了不允许改的能力、出路、证据或结局。
沿后续镜头追踪剩余功能、碎片、人体限制与空间，不因镜头更近、换方向或离画就恢复。文字核对只证明设计与交接的可检查性，实际视觉与动态效果仍待媒体核验。
