# 家庭戏导演判断：匿名对照与迁移检查

用于技能升级或用户要求的拍法比较。生产完整方案继续使用 [review-protocol.md](review-protocol.md) 的 rubric-v1；本页不替换、重算历史验收，也不把每次日常创作变成多版本实验。

## 建立可比较输入

- 冻结剧本、关系前后文、观众已知/未知、表达目标和制作限制。
- 比较双方获得相同内容、格式及篇幅目标；记录实际篇幅、模型和生成次数。换模型、额外上下文或多次挑选优秀样本都是混杂因素，须披露。
- 使用升级前快照与新版技能各做一次候选；若进行关键修订，另存版本并重评受影响结论，不能替换原试验记录。
- 样例覆盖隐性冲突、正面争执、未完成和解。加入台词相同而已知人物意图不同的独立输入，检查可观察的设计是否随上下文调整。不能把变体串成一场的连续事件。
- 未用于写方法卡的新场景可作为迁移探针；协调者知道其内容、样本量小的单轮测试不能称统计泛化证明。

## 评委看什么

提供冻结输入、匿名方案、预先保存的标准。隐藏作者/模型/技能版本、生成顺序、方法名称、自评分、运行记录和其他评委结论；保留与创作判断有关的理由。不要为匿名修改实际拍法。

标签映射及实际文件 hash 由协调者保存。两位评委独立上下文开始，一位先看 X 再看 Y，另一位相反；记录顺序与各自偏好。两个评委意见相同也不能据此声称已排除顺序偏差。需要测同一评委的顺序效应时另做新上下文重复，并披露重复限制。

共享文件系统只提供流程约束。检查匿名内容后可记录 L1，独立上下文可记录 L2；没有实际权限阻断及拒绝访问验证，不记录 L3 或严格双盲。同模型的多个评委可能共享偏差。

## family-decision-probe-v1

局部片段使用以下五维，各 0—4 分，等权。每维都须给输入段号/镜号证据，不以更多术语、更多镜头或更长文本加分。

1. **关系与潜台词**：意图、变化和歧义有依据；未完成的靠近没有被拍成已和解。
2. **表演与调度**：动作可复述、反应有触发、多人位置清楚、关键接触先后成立。
3. **镜头作用**：景别、机位、构图、移动或静止、切点服务特定剧情任务。
4. **信息与忠实度**：锁定对白/事件/结果/知情顺序保留；可见或可听证据没有被擅改。
5. **时长与交付清晰度**：动作和反应有时间发生，主方案能直接读懂，关键条件不藏附件。

0 缺失或矛盾；1 多为泛化指令；2 能执行但作用依据弱；3 具体连贯且符合目的；4 有层次、取舍和依赖。未知用 unknown，不当零；必要维度缺证据时不算总分。不设统一“高分保证”或强制胜出。

另列**条件敏感性**：在相同台词、不同前文的输入中，逐项比较可观察的动作、构图、关注对象或切点；判断差异是否得到上下文支持。合理的相同选择不自动失败；仅改分析形容词不足以证明有迁移能力。

擅改冻结事实、提前泄露信息、遗漏关键事件/对白、动作空间不成立为阻断项，不能用加权平均掩盖。审美偏好与硬缺陷分开。选择 preference / tie / inconclusive，保留分歧；文字判断不证明成片质量。

## 保存与报告

保存输入与技能快照/hash、创作任务、原始输出、匿名包/hash/映射、两份原始评审、问题处置和结论。报告区分：

- 安装/链接与格式可读；
- 本次样本的实际行为和文本评审；
- 方法是否显示稳定优势（证据不足可以明确无结论）；
- 未做的预演、观众测试和真实作品试用。

修订只根据定位到的具体问题，保留原始输出与评审。若新版并未胜出，技能可以记录为“已加入方法，尚未证明增益”，不能把规则更多等同于艺术判断更好。
