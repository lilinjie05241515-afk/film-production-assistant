# 关系戏方法

用于试探、谈判、靠近、退让、隐瞒、照顾或决裂。只加载当前关系所需的前后场状态；不将性格概括当作每一句台词的动机。

都市情感、亲子/夫妻和家庭群像的具体拍法判断，继续读 [家庭关系拍法判断](family-direction.md)。其中案例按人物反应、关系空间、信息限制检索；不把导演名字当成拍法理由。

1. 分开写各人物本场想获得的外在结果、对另一人的当下判断、愿意付出的代价。无原文依据的内心解释标 `director_open` 候选；有意歧义保留多解。
2. 将节拍标在关系变化处：谁的行动迫使谁换策略。台词说出以前、停顿当中、听完以后分别发生什么可见动作。
3. 给演员可执行动词与对象，例如“把椅子让出半步使她能离开”而非“更温柔”。对方必须接收、拒绝或误读该行动，并有可见调整。
4. 距离、面向、共同或分离的视野、接触物体可承载关系变化；构图只在这些变化需要被观众读到时服务它们。
5. 沉默须有任务：等待答复、保住体面、观察对方是否行动等。说明观众得到的新信息；没有信息不必机械加停顿。

输出简表：人物目标｜行动/对象｜对方反应｜策略调整｜关系前后状态｜剧本依据｜解释范围。检查单方独白、无因反应和表演统一化；不要替剧本规定所有台词只能有一个潜台词。
