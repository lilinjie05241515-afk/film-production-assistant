# 证据、素材与核看范围

## 资料优先的研究顺序

默认按以下顺序开展研究；用户明确指定直接核看上传视频或整片拉片时，优先遵循指定任务。

1. **先找官方高清图像与公开详细资料**：优先片方／发行方的剧照、正式宣传资料包和制作说明，主创及制作团队的公开访谈与工艺记录，以及专业机构、专业刊物和学术研究中的详细分析。图像检查原始出处、实际可查看尺寸、素材身份与版本；文字核读可访问的正文，记录作者、机构、发表时间、论据和引用。搜索摘要、转载标题或“权威”自称不能代替核读；无法访问正文时只作线索。
2. **先综合，再列出视频核验重点**：比较已核资料，整理可见的视觉特征、来源明确的制作意图、可迁移机制及分歧，形成简短的场景与问题清单。区分图片中的直接观察、作者／主创的陈述和本次分析；不把文章观点当作已经亲自核看的成片事实，也不照搬他人的结论。资料足以确定重点后转入视频核验；找不到足够资料时记录缺口并继续，不以资料齐全为前提无限搜索。
3. **再找视频，核实关键问题**：依据前一步定位的场景检查表演、走位、镜头运动、剪辑、声音，以及剧照能否代表该版本正片。需要在线查找片源时优先按 [LibreTV 流程](luoxiaoji-tv.md) 执行；已有合适视频可直接核看。没有视频的结论限定为资料研究；主张全片规律仍需相应的场景覆盖，不因先有详细文章而缩小必要核验范围。

该顺序决定获取材料的先后，证据能支持什么仍由素材身份、质量和实际核看范围决定。官方图像可能是现场摄影或宣传处理图，专业分析也需检查论据；动态图像和最终声音不能由静态图文替代。

## 三种输入路径

1. **用户上传或指定本地视频**：记录绝对路径、版本／文件名、时长与音视频轨道；需要可追溯性时记录文件哈希。用当前环境可用的视频工具核看连续场景与声音；关键帧提取、镜头检测和联系表可辅助定位，但抽帧本身不能证明语速、动作节奏、声音或剪辑动机。保存的关键帧标原文件、时间码和分析用途。长片先覆盖全片场景，再根据剧情转折、关系变化与视听方法变化挑选需要细拆的段落，列出没有细看的范围。
2. **公开可访问视频**：先确认是否为正片、加长版、预告、片段或幕后花絮，并记录实际播放的起止时间。优先官方放映页、片方／发行方视频、创作者与制作团队发布的内容。若页面只给摘要或预览图，不写成已经看过完整视频。遵守访问与权利条件，不通过下载来规避播放、展示或访问限制。
3. **仅有图片／文字资料**：仍可研究剧情梗概、设计意图与制作工艺，但标题注明“基于现有资料”；镜头运动、时长、切点、最终声音、色彩流程等无证据项留待核。将官方剧照、截图、剧本版本、制作手册、访谈、专业或学术分析各自标明，不互相替代。

三种输入路径描述素材的处理方式，不改变上述默认研究顺序。进入视频查找时，最终采用哪些片源由版本、实际可播放范围和质量决定；LibreTV 之外的公开视频优先片方、发行方和制作团队。优先检索顺序不代表证据可信度排序。

## 素材质量与结论适用范围

- **分开检查三个环节**：源视频／图片、截取或转换过程、实际送入分析的图。可核实时记录源分辨率、输出图片尺寸、播放器缩放／裁切，以及已知的压缩、增强和 HDR／SDR 转换情况；读取不到的参数保持未知。清晰度标签、文件像素尺寸或较高码率本身不能证明细节真实且完整。
- **检查与判断有关的画面**：构图需要空间与人物位置可辨，材质需要关键区域有真实细节，光色需要可信的亮度与颜色呈现，动态与声音需要连续声画。可将清楚的 1080p 作为优先寻找的起点，不设所有作品共用的最低分辨率，也不将 4K 自动认定为合格。
- **减少截取损失**：获准本地视频优先直接提取原尺寸帧，必要时记录色彩转换；播放器截图注明截图身份及已知缩放限制。联系表和缩略图用于定位，关键细节回到原尺寸单帧和必要局部裁切核看。图被放大不意味着恢复了原始细节；用相邻帧或同版本同镜头复核，避免把运动模糊或加载未完成的画面当成稳定风格。
- **按结论标注用途**：对受质量影响的证据，注明“可用于当前判断／仅支持部分判断／不足以支撑”，并写清可用与待核维度。压缩糊、暗部损失、过度锐化、降噪或色彩转换异常不能直接归纳为柔焦、低调照明、颗粒、材质或调色风格；它们也可能与原片表达有关，需换源或用制作资料核对。
- **换源与补证**：排除截取损失后，静态细节优先回查或补充官方高清图像及制作资料；涉及成片呈现、动作与声音的问题，用同版本可靠连续片源核验，必要时换源。确认图片是正片截帧、现场摄影、宣传修图还是幕后材料；不同剪辑／修复／调色版本分开登记。静态资料不能替代动作、切点和声音证据，单张精美剧照不代表全片规律。
- **阻断误判传递**：AI 放大、修复、降噪或锐化的结果不能证明原片缺失的细节；如使用辅助增强，保留原始版本并明确标注。质量不足的维度暂不进入已确认风格归纳与提示词，仍可交付其他有依据的判断。发现旧结论受画质影响时，复核并修订对应报告与限制词，记录受影响项，不能只替换配图。

质量记录放来源台账；正文图注仅写会影响当前判断的限制，避免为每张图重复整套检查表。

## 来源台账最低字段

| 字段 | 写法 |
| --- | --- |
| 作品身份 | 片名、年份、版本、集数或片段；避免院线版与加长版混写 |
| 来源 | 原始 URL 或绝对路径，发布者／机构，访问日期 |
| 实际核看 | 连续视频的起止时间、单帧时间码、图片数量、文字页码；区分“打开页面”和“播放视频” |
| 保存与权利 | 是否保存本地，保存位置；许可已知、未知或有限；是否仅能做内部研究导航 |
| 证据类型 | 正片画面／音轨、预告／片段、单帧、剧本、主创制作陈述、机构研究、二手评论、个人推导 |
| 画质与适用范围 | 可核的源／截图尺寸、截取方式、已知转换或增强、质量疑点及可支持的判断；聚合站另记片源／线路与集数 |

判断应使用与结论相配的证据：单帧可证明构图、可见道具和姿态；连续画面才支持动作与切换；实际听到的音轨才支持具体声源、入退与混音；主创访谈可证明受访者的意图和工艺说明，不能自动证明每个镜头的最终实现；剧本可证明该版本写法，不等于成片。搜索摘要仅作找来源的线索。来源之间矛盾时写出差异和可能原因，不静默合并。

## 图文证据卡

每个关键例子写：`场景与时间码／图片来源 → 直接可见或可闻 → 创作解释 → 支持程度与另一种可能 → 此例对作品的功能`。图片优先用用户获准素材或合法可显示的原出处预览；不可嵌入时用来源链接、时间码和原创空间示意图说明。示意图必须标为示意，不冒充原片画面。
