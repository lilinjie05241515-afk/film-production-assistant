# 内容制作的相关检查

内部选取相关检查，避免把所有媒介的要求一次问给用户。纯写作、小型修订和完整影视制作的方案规模不同。

| 检查角度 | 应识别的遗漏 | 合适的证据或方案输出 |
| --- | --- | --- |
| 意图与对象 | 表达什么、给谁、观看或阅读场景；个人表达是否足够 | 用户原话、已有作品定位；不强加商业目标 |
| 核心体验 | 情绪、信息、冲突或互动如何发生；首尾和关键转折 | 可复述的体验流程或内容结构，必要时具体片段 |
| 事实与设定 | 资料来源、正史或已确认版本、角色身份和关系 | 源材料、版本引用；新增方向仍是候选 |
| 表达与形式 | 媒介、长度、视角、风格、声音与节奏 | 针对实际交付的结构、样例或约束；无须全做样片 |
| 资源与边界 | 素材、角色、工具、授权、预算、时限、发布平台 | 可取得素材与限制清单；附件存在不代表权利可用 |
| 制作与验收 | 任务顺序、依赖、输出格式、质量判断和修改空间 | 可执行制作安排、实际成品检查；生成成功不等于用户认可 |

文字审查可以发现结构或连贯性问题，实际小样可以验证制作可行性，观众试读或试看片段才提供受众体验证据。模型自评或多模型赞同不能替代观众反应。

内容扩写、角色设计、生成图像或制作样片均属于实际制作，要以相称方案和已有授权为依据。用户仅请讨论或登记时停在讨论；已有明确制作请求与方案时持续交付，不要求再次说“开始”。
