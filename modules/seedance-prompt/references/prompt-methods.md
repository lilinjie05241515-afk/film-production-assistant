# 从导演意图到可见声画

以下是视频提示词的写作方法和检查准则，不是 Seedance 的精确执行保证。资产设计模式可复用空间、尺度、材质等方法，但其三版图像提示词按 asset-design.md 交付，不套用本文件的视频三块输出约定。

## 执行转译与输出边界

内部先核对采用的剧本、人物小传、故事大纲和导演拍摄建议，再编写模型输入。剧本决定事件、对白和结果；人物小传约束身份、关系与行为；大纲约束因果与信息揭示；导演建议负责构图、景别、机位、运动和切换。普通导演建议应落实为一种明确拍法；用户已经锁定的镜头、机位和剧情不得自行替换。

每个独立生成单元只输出三块：**风格总控 → 场景与角色锚定 → 分镜**。风格总控包含本段适用的影调与画质、演员表演形式、镜头默认语言、声音与对白规范、画面与必要负面约束，并在每个独立单元中展开。场景与角色锚定交代稳定身份、空间、道具、开场状态和有效参考范围。分镜按发生顺序融合构图、运动、动作、对白、拟音与反应；结束状态写进最后一个分镜。

资料版本、原镜号映射、估时依据、参考素材状态和检查过程留在内部。默认成稿不带外层简报、候选说明、审查报告、对用户的解释或待填占位符。没有来源约束的普通拍摄细节可补成一致的执行选择，内部区别于来源事实；关键设定缺失或冲突先在成稿前独立澄清。

## 场景参考：可用于调度的环境图

制作或规划环境参考图时，优先考虑 3/4 斜侧视角，让相交墙面、物体侧面、前后层次和可通行区域可辨。不要把 3/4 理解成一律精确旋转 45°，也不要套用到所有成片镜头或人物资产。

正面舞台、仪式对称、建筑立面、主观镜头、已选构图等有明确用途时，保留它们；必要时建议增加一张空间辅助参考，而不是覆盖原构图。

选择一个或少量有辨识度的固定参照物，例如柱子、落地灯、沙发、台阶。位置叙述围绕参照物展开，优先使用已有物件。确需新增参照物时，先判断是否影响既定场景或剧情：普通布景细节可作为执行设计补足并内部记录；改变已定布局、关键道具或剧情条件时，先独立澄清。默认提示词只写最终采用的场景，不附候选说明。参考画面需便于判断人物站哪里、朝哪里、相机如何进入，而不只是装饰丰富。

内部先区分参考用途；正文只写实际生效的约束。仅作外观参考时，限定为建筑、材质和空间结构，并单独给出成片机位与人物构图；作为首帧时，明确保持其构图和起态。参考用途不同，不能混成一条指令。没有真实引用标签时不虚构编号；已有文字足以描述场景时，直接写完整文字锚定，不留下“待绑定”占位符。

## 空间地图：固定世界位置，另写镜头投影

同一场景先选择不随摄影机转动的基准，如“从入口朝室内看”。后续用“入口侧、窗侧、平台后方”等稳定称谓；画面左/右仅描述当前镜头投影。

建议用几行自然语言：

```text
固定基准：从南侧门口望向北墙。
平台在房间中央；石柱在平台东侧约三米；仪式区在平台西侧。
门口到平台之间留有可通行走道；主光从平台北侧照向入口。
人物甲在石柱西侧约一米处，身体朝门口；人物乙在入口内侧朝向平台。
本镜摄影机在门口偏西侧，镜头朝向平台；后续反打仍保持既定人物轴线关系。
```

以上仅为方法示例，不能自动加入项目。距离若未经设定，可在不改变已定布局和剧情的前提下选择合理近似值，正文用“约”表达，内部记录为执行设计；不能假称由图片精确测量得来。对剧情或已锁调度有实质影响的距离先核清。

- 摄影机换边时，世界中的东/西不变，画面左右可能交换。
- 写“角色右手”时指解剖学右手；写“画面右侧”时指当前镜头，不相互替代。
- 需要跨轴时说明跨轴过程或重新建立关系的镜头，不能为了“不越轴”抹掉导演已设计的运动。
- 复杂场景可补一张简明文字平面图，但最终模型输入仍用自然语言说明关键关系。

## 尺度：用同画面的比例支持数字

巨大/微小主体除设定尺寸外，选择观众熟悉的参照物，写清二者相邻或大致同一纵深，避免把远小近大误作真实尺度。

例如“普通成年人站在巨人脚边，头顶尚不到脚踝；同一地面的公交车车顶低于巨人小腿”。具体比例必须与角色设定相容；不要同时写“30 米巨人”和与它不符的掌宽/建筑层数。

跨镜头保持相对比例，但特写不必硬塞一个完整人物当尺子；可用同一已定道具、手部、门框局部作尺度证据，或由前一建立镜头承接。

## 摄影：术语附带可见结果

优先说明摄影机的相对位置/远近、机位高度、人物占画比例、画面截取范围、前中后景与清晰度，再用焦段辅助表达。

| 目标 | 可见表述示例 |
|---|---|
| 长焦倾向的人物特写 | 摄影机在走廊较远端，画面只截取人物面部到肩部；后方门框在画面中显得较大、彼此层叠，背景细节虚化。 |
| 广角倾向的环境人物镜头 | 摄影机贴近门内人物，保留其半身与两侧墙面；近处伸向镜头的手明显大于远端物件，地面线条延伸到画面边缘。 |
| 景深内的双人反应 | 前景人物肩部只占一角，中景说话者与后景听者都足够清楚，能辨认后者转头停顿。 |
| 连续推进 | 摄影机沿既定通道缓慢前移，由双人中景收紧为一人近景；空间透视持续变化，中途不切镜。 |

透视关系主要由机位决定，不能只靠“85mm”代替空间设计。景别变化不一定意味着剪辑；“切到近景”和“推进至近景”必须区分。

导演材料中的普通备选建议，需要在内部判断后落实成唯一、连贯的拍法。例如“可以推近或横移”不能原样进入成稿；正文应写明确的起始构图、运动轨迹、落点及是否切镜。默认镜头语言与本镜具体设计冲突时，以已采用的本镜设计为准；不能为迁就默认运镜而改掉已锁镜头。

用户提供的约 84°、47°、29°、8°可记录为该作者的广角到超长焦示例。没有水平/垂直/对角视角定义、传感器与裁切条件时，不把这些角度换算成唯一焦距，更不作为模型参数或执行承诺。

## 动作：因果、接触、重量与结果

按所需粒度描述：

**起态 → 发力/运动 → 接触 → 承重/受力与环境反馈 → 调整 → 结果与新末态。**

不必每个动作都写全部步骤。把篇幅用于决定可信度或剧情的接触点。

- 递交重物：接手者先托住底部、手肘下沉并调整重心，原持有者再松手；结尾明确归谁持有。
- 突然停止：身体停下后液面继续向运动方向涌起，再反向晃回并逐渐平稳；不无依据添加洒水结果。
- 附着黏液：说明附着区域、重力方向、流动速度、拉丝或断裂，以及接触衣料后留下的湿痕。
- 重臂：肩部向承重侧下沉、躯干补偿、落下后产生合适的接触反馈。
- 抱扶/跳跃：起跳支撑点、飞行方向、落点、缓冲与站稳要连贯。承重表面是硬桌时，不因“强调物理感”凭空写纸面或桌面塌陷。

奇幻、动画、失重、巨物等按项目的物理规则表现：保留规则内可读的因果，不擅自取消已经设定的悬浮或超常能力。

情绪可写“犹豫”，再接“手已伸向门把，却在触碰前停住，目光退回桌上的照片”。避免一个短镜头同时要求多次互斥情绪与细小动作。

## 台词、声音、切镜的同一时间顺序

将说话者、音色/声音参考、当前语气、逐字内容、口部状态与反应触发写在所属小镜头内。音色是跨镜头特征，语气是当下表演；没有音频或设定时不要虚构“已锁定声音”。

示意：

```text
【镜2｜门侧双人中景】
人物甲把托盘放稳，杯底碰桌发出一声轻响。他看向人物乙，压低声音说：“先别开门。”
人物乙听完后，握门把的手停住；门外脚步声又向前近了一步。
【镜3｜切至人物乙近景】
摄影机仍在门内同侧，人物乙侧脸占画面右侧，门缝留在左侧。他先看门缝，再回望甲。
```

这是原创格式示例，不是任何项目的台词依据。不要自动套用“所有反应都必须等句末”；倾听、打断、重叠对白或悬疑先声后画均按剧情安排。

需要说话时切到听者，明确“甲继续画外说，乙只听不张口”；不要把合法的声音桥或反应镜头写成平台禁区。

## 时间与容量

先确定动作和对白的依赖关系，再决定是否需要秒数：

- 自然节拍：适合单动作、表演流、一般叙事；用“先、说完后、短暂停顿、最后”等词。
- 时间窗口：适合多人轮次、关键揭示、音乐卡点和原导演时间约束。
- 明确时间范围：适合局部编辑、固定时长要求；所有范围必须与所选总时长一致。

台词试读是估时优先依据。没有音频时在内部记录粗估假设，并留出呼吸、停顿、反应和不并行的动作时间；不把估算过程或可靠性说明写进默认提示词。若明显放不下，在允许范围内选择可容纳内容的时长或分段，成稿只呈现选定方案；固定总时长、已锁镜头与完整对白无法同时满足时，先独立澄清。只有用户授权台词压缩/改写才改词。

不要将“每镜至少 3–6 秒”“最多 3–4 镜”“一句话内绝不切镜”写成模型硬规则；也不能承诺明确编号就会百分之百精准。

## 文字、风格与精简

内部核对剧情文字的叙事作用，提示词写**准确文本、承载物、出现位置和必要可读时间**。将剧情道具文字、片内字幕、后期字卡与无关生成字幕分开处理。

已确认需画面出现的价格或署名不能一律抹掉。未确定文字方案时，先判断直接生成或后期合成对叙事和既定制作流程的影响；关键冲突在成稿前解决，最终提示词只写本次生成承担的画面，不并列两种备选建议。不能声称文字必定正确，也不能把提示词里的“无水印”当成可以取消平台强制水印。

用少量相关约束解决实际风险，例如“签名栏保持空白，笔尖始终未接触纸面”。避免追加一整页通用负面词。精简重复风格堆叠，保留真正影响站位、因果、声音、尺度和末态的细节。

交付前在内部确认每一独立单元含所需风格控制与锚定、没有依赖“同上”或上一条提示词、没有未决选项与占位符。场次和镜号可用于模型定位内容；来源说明、采用理由、检查结论与复制操作说明不进入默认成稿。
