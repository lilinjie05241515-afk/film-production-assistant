## A. 创建请求中的作者方法摘要

- 实际查看：用户粘贴的摘要与其中时间范围。
- 未查看：摘要所述原视频；没有据此确认作者身份、原片全部论证或效果。
- 采用性质：用户要求纳入的方法，按适用条件实现；不是官方参数或严格模型定律。

## E. 2026-10-23 用户确认的视频输出约定（2.0.0 保留至今）

用户在本对话中要求：根据剧本、人物小传、故事大纲和导演拍摄建议，交付可直接复制到视频生成模型的具体提示词；成稿不包含面向用户或他人的解释性说明。用户确认后执行本次升级。以下决策覆盖初版格式与旧交接中冲突的呈现方式：

- 每个独立生成单元采用 **风格总控 → 场景与角色锚定 → 分镜**。风格总控包含影调与画质、演员表演形式、镜头默认语言、声音与对白规范、画面与必要负面约束。
- 每条展开本段适用的全局控制，使其完整自包含；默认不再输出外层简报、元数据表、解释、审查报告或待填占位符。版本、素材映射、原镜号关系和静态检查留在内部，用户另行索要时再提供。
- 导演材料提供拍摄和运镜建议。普通备选建议在内部落实为一种明确执行拍法；已锁镜头、剧情、对白与结果不能静默改动。剧情和人物依据仍来自所采用的故事材料。
- 普通拍摄细节可以补足，但内部不得冒充来源既有事实；关键冲突在成稿前独立澄清。没有真实参考绑定时可使用足够的文字锚定，不编造引用标签。
- 动作、台词、声音、反应继续在所属分镜融合，保持场景空间、可见尺度、接触物理与首尾状态的连续性。

这是用户对视频模式的交付决定，不是对即梦平台新增能力或生成效果的实测结论。

## F. 2026-10-23 资产 Agent 扩展（3.0.0）

用户在本对话中要求把提示词技能升级为 Agent，新增从剧本筛选主要人物、场景和道具并提供三版建议提示词的能力；随后明确选择“每个主要人物、场景、道具各给三套设计方向与提示词”，并授权升级与测试。

- 保留原调用名，以任务路由、项目工作状态和三种主要模式实现 Agent：资产筛选、资产设计、视频提示词；不因此安装后台服务、自动创建对话或生成媒体。
- 三版是每项资产在已定剧情、人设和全剧风格范围内的不同视觉设计；不等于三视角、三种剧情状态或三套全项目风格。
- 资产设计模式交付必要清单、简短方向差异及各版独立图像提示词；说明与选择状态在提示词框外。视频模式继续遵守上一节的纯三段式输出。
- 已选资产默认复用；别名归并、父资产与状态分开；关键一次性道具不能仅因出现次数少被漏选。
- 记录每项的候选、推荐、明确选型、有效视觉锚点及实际媒体状态，后续视频只展开有效版本。用户明确授权代选时可以执行，推荐本身不等于采用。
- 参考图提示词的图像平台未指定时使用通用中文；没有真实生成与回看时，不声称通过图像或视频效果验证。
